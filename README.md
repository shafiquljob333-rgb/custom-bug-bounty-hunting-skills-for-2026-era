🧠 Agentic Bug Bounty Hunting – How It Works
The repository is built around the concept of agentic hunting: an AI agent (or a human assisted by AI) follows a structured yet adaptive workflow:

Perceive – Gather target information using reconnaissance skills.

Reason – Evaluate attack surface and select relevant skills.

Act – Execute skills against the target, collecting evidence.

Validate – Use built‑in verification steps to confirm findings.

Report – Generate professional, reproducible reports.

Each skill defines:

Trigger conditions – When the skill should be activated.

Steps – Sequential or conditional actions to perform.

Success criteria – How to determine if the skill succeeded.

Validation logic – Methods to reduce false positives.

Output schema – Standardized format for integration.
